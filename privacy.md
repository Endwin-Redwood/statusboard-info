# Privacy Policy

_Last updated: October 16, 2026_

StatusBoard is a personal, self-hosted family dashboard. It runs on a private home computer and is used by one household. This policy explains what data it accesses and how that data is handled.

## Data accessed

When the owner signs in with Google, StatusBoard requests these **read-only** permissions:

| Permission | Purpose |
|---|---|
| Google Calendar (read-only) | Show upcoming calendar events on the home display |
| Google Tasks (read-only) | Show open tasks on the home display |

StatusBoard cannot create, change or delete calendar events or tasks.

## How data is used and stored

- Calendar and task data is fetched from Google only to show it on the home display.
- That data is held in the app's memory for a few minutes, and is not stored long-term.
- The Google sign-in token is stored only on the home computer that runs StatusBoard.
- Server logs are kept on that same computer and are deleted automatically after no more than 72 hours.

## Data sharing

Google user data is **not** sold, shared or sent to any third party, and is not used for advertising, analytics or AI/machine-learning training.

StatusBoard does contact one other service, the Open-Meteo weather service, to get the local forecast. Only the configured location coordinates are sent to Open-Meteo. No Google data is sent.

StatusBoard's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Revoking access stops StatusBoard from reading any further data.
